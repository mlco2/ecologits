# AGENTS.md

## Formatting

- Never hard-wrap prose. Write each paragraph, list item, or admonition body on a single line in Markdown and other documentation files; the IDE already wraps text.
- In Python, only break docstrings and comments when a line would exceed ruff's 120-character limit, never earlier.

## Data files

- Never edit files in `ecologits/data/` directly; they are generated by an internal repository's automated update and export pipeline, so any manual change would be overwritten.
